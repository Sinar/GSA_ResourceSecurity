An independently measured visual library of 71 data centre buildings in Malaysia — satellite-derived footprint, power, water, and carbon estimates.

Data is independently derived from satellite imagery and, where available, operator-disclosed capacity. Estimates should be read as order-of-magnitude figures, not precise measurements. See the companion Full Project Methodology and Verification & QA Report for full caveats.
